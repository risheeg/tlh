# Database Schema

## Overview

The TLH backend uses a PostgreSQL database hosted on Neon. The live `public` schema contains seven base tables and two portfolio views. The `vault_ingest` schema stores AI-indexed personal document metadata. Daily price-history backups are stored separately in a local SQLite table.

## Base Table: `users`
Stores core user identity and account-level metadata.

| Field | Type | Constraints | Description |
| :--- | :--- | :--- | :--- |
| `id` | UUID | Primary Key | Unique identifier for the user. Generated by the app. |
| `email` | String | Not Null, Unique, Indexed | User's email for login and notifications. |
| `created_at` | DateTime with time zone | Not Null | Timestamp of account creation. Set by the app in UTC. |

---

## Base Table: `accounts`
Represents a real-world brokerage, bank, or holding entity.

| Field | Type | Constraints | Description |
| :--- | :--- | :--- | :--- |
| `id` | UUID | Primary Key | Unique identifier for the account. Generated by the app. |
| `user_id` | UUID | Not Null, Foreign Key (`users.id`), Indexed | Owner of the account. |
| `name` | String | Not Null | User-defined account name. |
| `type` | `accounttype` | Not Null | Account category: `taxable`, `retirement`, `savings`, `checkings`, or `cma`. |
| `institution` | String | Nullable | Name of the provider, such as a brokerage or bank. |
| `created_at` | DateTime with time zone | Not Null | Timestamp of account creation. Set by the app in UTC. |

---

## Base Table: `lots`
Stores individual tax lots. Lots must only be associated with `taxable` accounts.

| Field | Type | Constraints | Description |
| :--- | :--- | :--- | :--- |
| `id` | UUID | Primary Key | Unique identifier for the lot. Generated by the app. |
| `user_id` | UUID | Not Null, Foreign Key (`users.id`), Indexed | Owner of the lot. |
| `account_id` | UUID | Not Null, Foreign Key (`accounts.id`), Indexed | The taxable account holding this lot. |
| `ticker` | String | Not Null, Indexed | Stock or fund symbol. |
| `quantity` | Numeric (18, 8) | Not Null | Number of shares currently held. |
| `original_purchase_price` | Numeric (18, 8) | Not Null | Price per share at acquisition. |
| `current_adjusted_basis` | Numeric (18, 8) | Not Null | Materialized IRS-compliant adjusted basis per share. |
| `purchase_date` | Date | Not Null | Date of acquisition. |
| `status` | `lotstatus` | Not Null, App default: `active` | Lot lifecycle state. |
| `external_ref_id` | String | Nullable, Unique, Indexed | Deterministic identifier used for idempotent imports. |

## Base Table: `aggregate_positions`
Stores high-level position totals for accounts where lot-level tracking is unnecessary.

| Field | Type | Constraints | Description |
| :--- | :--- | :--- | :--- |
| `id` | UUID | Primary Key | Unique identifier for the aggregate position. Generated by the app. |
| `user_id` | UUID | Not Null, Foreign Key (`users.id`), Indexed | Owner of the position. |
| `account_id` | UUID | Not Null, Foreign Key (`accounts.id`), Indexed | Account holding this total. |
| `ticker` | String | Not Null, Indexed | Asset symbol. |
| `quantity` | Numeric (18, 8) | Not Null | Total units held in the account. |
| `last_updated` | DateTime with time zone | Not Null | Timestamp of the latest update. Set by the app in UTC. |
| `cost_basis` | Numeric (18, 2) | Nullable | Total cost basis for the aggregate position. |
| `asset_type` | `assettype` | Not Null, DB/App default: `Equity` | Asset category, currently `Equity` or `Cash`. |

## Base Table: `stock_prices`
Stores the latest market-data record for each equity ticker.

| Field | Type | Constraints | Description |
| :--- | :--- | :--- | :--- |
| `ticker` | String | Primary Key | Stock or fund symbol. |
| `price` | Numeric (18, 2) | Not Null | Latest known price. |
| `last_updated` | DateTime with time zone | Not Null | Timestamp of the latest price sync. |
| `exchange` | String | Nullable | Exchange used for external price lookup. |
| `category` | String | Nullable | Asset category used by portfolio summaries. |
| `expense_ratio` | Numeric (10, 6) | Nullable | Fund expense ratio, when available. |

## Base Table: `stock_splits`

| Field | Type | Constraints | Description |
| :--- | :--- | :--- | :--- |
| `id` | UUID | Primary Key | Unique identifier for the split record. Generated by the app. |
| `ticker` | String | Not Null, Indexed, Unique with `effective_date` | Ticker affected by the split. |
| `effective_date` | Date | Not Null, Unique with `ticker` | Date the split took effect. |
| `split_numerator` | Integer | Not Null | Numerator of the split ratio. |
| `split_denominator` | Integer | Not Null | Denominator of the split ratio. |
| `created_at` | DateTime with time zone | Not Null | Timestamp when the split record was created. Set by the app in UTC. |
| `applied_at` | DateTime with time zone | Nullable | Timestamp when the split was applied to holdings. |

## Base Table: `net_worth_snapshots`
Stores historical total net worth and portfolio breakdowns.

| Field | Type | Constraints | Description |
| :--- | :--- | :--- | :--- |
| `id` | UUID | Primary Key | Unique identifier for the snapshot. Generated by the app. |
| `user_id` | UUID | Not Null, Foreign Key (`users.id`), Indexed, Unique with `snapshot_date` | User captured by the snapshot. |
| `snapshot_date` | Date | Not Null, Indexed, Unique with `user_id` | Date represented by the snapshot. |
| `total_net_worth` | Numeric (18, 2) | Not Null | Total net worth at snapshot time. |
| `breakdown` | JSONB | Not Null | Structured breakdown by category, account, and asset type. |
| `created_at` | DateTime with time zone | Not Null | Timestamp when the snapshot row was created. Set by the app in UTC. |
| `comments` | Text | Nullable | User-editable notes for the snapshot. |

## Schema: `vault_ingest`
Stores personal document metadata created by the Cloudflare vault ingest pipeline. Original files and parsed JSON artifacts live in R2; Neon stores the searchable catalog row.

### Base Table: `vault_ingest.documents`

| Field | Type | Constraints | Description |
| :--- | :--- | :--- | :--- |
| `id` | UUID | Primary Key | Deterministic document identifier generated from the R2 inbox path. |
| `user_id` | UUID | Not Null, Foreign Key (`users.id`), Indexed | Owner of the document. |
| `upload_date` | DateTime with time zone | Not Null | R2 event timestamp for the original upload. |
| `processed_at` | DateTime with time zone | Not Null | Timestamp when the Worker finished classification and indexing. |
| `category` | String | Not Null, Indexed | Top-level document category: `tax`, `medical`, `finance`, `receipts`, `career`, `identity`, `insurance`, `property`, or `other`. |
| `subcategory` | String | Nullable, Indexed | Granular, strictly mapped label such as `1099_consolidated`, `statement_brokerage`, or `lab_result`. |
| `account_id` | UUID | Nullable, Foreign Key (`accounts.id`), Indexed | Reserved for linking to an account. |
| `r2_original_path` | Text | Not Null | Original R2 inbox key that triggered processing. |
| `r2_file_path` | Text | Not Null | Processed R2 key for the retained original file. |
| `r2_parsed_json_path` | Text | Not Null | R2 key for the model's parsed JSON sidecar. |
| `r2_markdown_path` | Text | Nullable | R2 key for the document's raw parsed Markdown text. |
| `file_size` | Integer | Nullable | Source object size from the R2 event. |
| `ai_model` | String | Not Null | Workers AI model used for classification. |
| `parsed_json` | JSONB | Not Null | Structured extraction output (versioned via `schema_version` inside the JSON). Note: `category`, `subcategory`, and `full_text_or_records` are stripped from this payload before storage to save space. |

## View: `portfolio_aggregated_positions`
Unifies active tax lots and aggregate positions into one book-value position stream.

| Field | Type | Description |
| :--- | :--- | :--- |
| `holding_id` | UUID | Deterministic holding identifier for lot aggregates, or `aggregate_positions.id` for aggregate rows. |
| `user_id` | UUID | Owner of the holding. |
| `account_id` | UUID | Account containing the holding. |
| `ticker` | String | Asset symbol. |
| `quantity` | Numeric | Total quantity for the holding. |
| `cost_basis` | Numeric | Total cost basis. For lots, derived from `quantity * original_purchase_price`. |
| `holding_type` | Text | `lot` or `aggregate`. |
| `asset_type` | Text | `Equity` for lots, or the aggregate position's `asset_type`. |

---

## View: `portfolio_holdings_enriched`
Adds price and classification data to `portfolio_aggregated_positions`.

| Field | Type | Description |
| :--- | :--- | :--- |
| `holding_id` | UUID | Holding identifier from `portfolio_aggregated_positions`. |
| `user_id` | UUID | Owner of the holding. |
| `account_id` | UUID | Account containing the holding. |
| `ticker` | String | Asset symbol. |
| `quantity` | Numeric | Total quantity for the holding. |
| `cost_basis` | Numeric | Total cost basis. |
| `original_purchase_price` | Numeric | Derived per-unit cost basis (`cost_basis / quantity`) when quantity is positive. |
| `holding_type` | Text | `lot` or `aggregate`. |
| `asset_type` | Text | `Equity` or `Cash`. |
| `category` | String | Asset category from `stock_prices`, or `Cash/Cash Equivalents` for cash. |
| `expense_ratio` | Numeric | Expense ratio from `stock_prices`, or `0` for cash. |
| `current_price` | Numeric | Latest price from `stock_prices`, or `1.0` for cash. |
| `market_value` | Numeric | Current market value (`quantity * current_price`), or cash quantity for cash holdings. |
| `price_last_updated` | DateTime with time zone | Latest price timestamp, or current UTC timestamp for cash. |

## Local SQLite Table: `stock_price_history`
Stores daily price-history backups outside Neon at `backend/var/stock_price_history.sqlite3` by default.

| Field | Type | Constraints | Description |
| :--- | :--- | :--- | :--- |
| `ticker` | Text | Not Null, Primary Key with `price_date` | Stock or fund symbol. |
| `price_date` | Text | Not Null, Primary Key with `ticker` | Date represented by the backup row, stored as ISO text. |

## Relationships

```
users
 ├── accounts                 (one-to-many)
 ├── lots                     (one-to-many, taxable accounts only)
 ├── aggregate_positions      (one-to-many)
 └── net_worth_snapshots      (one-to-many)

accounts
 ├── lots                     (one-to-many, type=taxable only)
 └── aggregate_positions      (one-to-many)

stock_prices
 └── portfolio_holdings_enriched (left join by ticker for equity holdings)

vault_ingest.documents
 ├── users                     (many-to-one)
 └── accounts                  (nullable association via account_id)
```

## Key Business Rules

- **Lots -> taxable accounts only**: A database trigger (`lots_enforce_taxable_account`) enforces that `lots.account_id` references an account with `type = taxable`.
- **Aggregate positions -> upsert**: Uploading a position for an existing `(user, account, ticker)` triple updates it in place rather than creating a duplicate.
- **Idempotency via `external_ref_id`**: Lot uploads with a duplicate `external_ref_id` are skipped so callers can safely re-submit.
- **One net-worth snapshot per user per date**: `net_worth_snapshots` enforces uniqueness across (`user_id`, `snapshot_date`).
- **One stock split per ticker per effective date**: `stock_splits` enforces uniqueness across (`ticker`, `effective_date`).
